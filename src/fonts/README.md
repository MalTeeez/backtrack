# Fonts

The app serves these fonts from this folder. Both use the SIL Open Font License 1.1 (https://openfontlicense.org).

- `VG5000-Regular.otf` is VG5000 by Justin Bihan, Velvetyne Type Foundry. It sets small text, like labels, buttons and tags.
- `ArchivoBlack-Regular.ttf` is Archivo Black by Omnibus-Type. It sets big and header text.

Commit Mono (`@fontsource/commit-mono`) sets the body text.
